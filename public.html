CTS Architecture Notice (MVP vs Production Multi-User Roadmap)

This platform is currently running as an interactive single-browser client MVP powered by browser localStorage. For full enterprise multi-user operation across multiple computers and smartphones, CTS requires:

  • Central Database: PostgreSQL / MySQL to store verified tutor records, transactions, and guardian requests centrally.
  • Role-Based Access Control (RBAC): Separate permission levels for Super Admin, Area Coordinators, Tutors, and Guardians.
  • Authentication & Security: JWT session tokens, encrypted passwords (bcrypt), and rate-limited API endpoints.
  • Direct WhatsApp & SMS Gateway: Integration with official WhatsApp Cloud API or BD SMS gateways (e.g. SSL Wireless) to dispatch verified alerts.
